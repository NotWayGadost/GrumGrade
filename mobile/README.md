# GRUMGrade — приложение для iPhone

Настоящее приложение (.ipa): иконка G, полный экран, поворот экрана. Внутри всё своё: 358 скинов с картинками, 24 кейса, шрифт.
Работает **без интернета и без сервера**: баланс виртуальный и хранится в телефоне.

На Windows iOS-приложение собрать нельзя, нужен Mac. Поэтому сборку делает бесплатный Mac-сервер GitHub, а на телефон ставим с Windows через **Sideloadly**.

---

## Шаг 1. Залить проект на GitHub (один раз)

1. Зарегистрируйся на https://github.com
2. Справа вверху **+** → **New repository** → имя `grumgrade` → выбери **Private** → **Create repository** (галочки README не ставь).
3. В папке проекта выполни (вместо `ТВОЙ_НИК` — ник на GitHub):
   ```bash
   git remote add origin https://github.com/ТВОЙ_НИК/grumgrade.git
   git push -u origin main
   ```
   Откроется окно входа в GitHub, войди.

Файл `.env` с паролем админки на GitHub **не попадает** (он в `.gitignore`).

## Шаг 2. Собрать .ipa

1. На странице репозитория открой вкладку **Actions**. Если спросит, нажми «I understand… enable».
2. Слева выбери **iOS-приложение** → справа **Run workflow** → **Run workflow**.
3. Подожди 10–15 минут, пока появится зелёная галочка.
4. Открой запуск, внизу в **Artifacts** скачай **GRUMGrade-ipa** и распакуй zip. Внутри `GRUMGrade-1.0.N.ipa`.

Дальше сборка запускается сама при каждом `git push`, если менялись файлы приложения.

## Шаг 3. Поставить на iPhone через Sideloadly

1. Установи **iTunes** и **iCloud** с сайта apple.com. Нужны версии с сайта, не из Microsoft Store.
2. Скачай Sideloadly с официального сайта https://sideloadly.io и установи.
3. Подключи iPhone кабелем, на телефоне нажми «Доверять этому компьютеру».
4. Перетащи `.ipa` в окно Sideloadly, введи свой Apple ID (лучше отдельный, не основной) и нажми **Start**.
5. На iPhone:
   - **Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл** (телефон перезагрузится, подтверди).
   - **Настройки → Основные → VPN и управление устройством** → твой Apple ID → **Доверять**.
6. Иконка **GRUMGrade** на домашнем экране, запускай.

**С бесплатным Apple ID** приложение работает 7 дней, потом его надо переподписать в Sideloadly (есть автопродление по Wi-Fi). С платным аккаунтом разработчика Apple ($99 в год) подпись живёт год.

В App Store такое приложение не пропустят: у Apple строгие правила для азартных игр.

## Для разработчика

- `node build-www.js` — собрать `www/`: копию `public/` без админки, `catalog.json`, `img/` с картинками всех скинов и шрифт. Картинки кэшируются в `.cache/`.
- `app.config.json` — Telegram, стартовый баланс, бонус и экономика внутри приложения.
- `ios-setup.sh` — название, иконка, экран запуска, статус-бар и ориентации (запускается на macOS).
- Сборка: `.github/workflows/ios.yml` (macOS, Xcode, `CODE_SIGNING_ALLOWED=NO`). Подписывает Sideloadly.
- Проверить приложение в браузере без сервера: `python -m http.server 3100 --directory mobile/www`.
- Цены в приложении зашиты на момент сборки. Обновить: `npm run prices` в корне, потом `git push`, и соберётся новая версия.
