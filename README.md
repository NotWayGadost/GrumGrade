# GRUMGrade

Апгрейдер и кейсы CS2. Node.js без зависимостей: встроенный SQLite, вход через Steam, provably fair.

## Запуск

Нужен Node.js 22.13+ (проверено на 24).

```bash
cp .env.example .env
npm start
```

Открыть http://localhost:3000. В `.env` по умолчанию `DEMO_MODE=1`: работают «Демо-вход» и бесплатное пополнение.

## Приложение на iPhone

**Настоящее приложение (.ipa)** работает без сервера и интернета. Собирается в GitHub Actions, ставится через Sideloadly. Пошагово: [mobile/README.md](mobile/README.md).

Ещё сайт работает как приложение (PWA): иконка на домашнем экране, полный экран, нижние вкладки, офлайн-режим.

1. Запусти сервер (`npm start`). Компьютер и телефон должны быть в одной Wi-Fi сети.
2. На iPhone открой в **Safari** `http://<IP компьютера>:3000` (IP показывает `ipconfig`, например `http://192.168.0.149:3000`).
   Если не открывается, разреши Node.js в брандмауэре Windows (частные сети).
3. Нажми «Поделиться» → **«На экран "Домой"»**. Появится иконка GRUMGrade.

Для настоящей установки «для всех» нужен домен с HTTPS (см. «Хостинг» ниже). Тогда приложение будет работать с любого iPhone и кэшироваться для офлайна.
Иконки генерируются командой `node scripts/make-icons.js`.

Приложение поворачивается. Горизонтально вкладки уходят в панель слева, колесо встаёт между слотами, вырезы экрана сбоку учитываются. Чтобы iPhone поворачивал экран, должна быть выключена блокировка ориентации.

### Онлайн и офлайн
- **Онлайн**: аккаунт на сервере (Steam или демо), общая лента дропов, вывод скинов.
- **Офлайн**: игра без интернета на виртуальном балансе, всё хранится в телефоне. Работают кейсы, апгрейд, бонус и provably fair. Балансы онлайн и офлайн не связаны. Переключатель в «Профиль → Офлайн-режим». Каталог берётся из последнего онлайн-захода.

### Режимы апгрейда
«Классика»: стрелка сверху, зона выигрыша идёт по часовой. «Снизу»: стрелка снизу, зона растёт в обе стороны. Это только анимация, результат одинаково честный.

## Админ-панель

`/admin` (или «Профиль → Админ-панель»). Пароль задаётся в `.env`: `ADMIN_PASSWORD`. Без пароля панель выключена.
- Статистика: игроки, онлайн, ставки, выплаты, профит, депозиты, выданное админом.
- Игроки: поиск, начисление и списание баланса, выдача предметов, бан.
- Выводы: подтверждение или отклонение заявок. Журнал: все действия админа с IP.
- Обновление цен одной кнопкой.

После 5 неверных паролей вход блокируется на 15 минут. Сессия админа живёт 12 часов.

## Прочее

- `TELEGRAM_URL=https://t.me/...` в `.env` — кнопка Telegram в шапке и в профиле.
- Ежедневный бонус: `BONUS_MIN`, `BONUS_MAX`, `BONUS_HOURS` (`BONUS_MAX=0` выключает).

## Структура

| Путь | Что там |
|---|---|
| `server/index.js` | HTTP-сервер, все API, живая лента (SSE) |
| `server/db.js` | Схема SQLite. Деньги хранятся в копейках |
| `server/auth.js` | Steam OpenID и сессии (httpOnly-cookie) |
| `server/fair.js` | Provably fair: `HMAC_SHA256(serverSeed, clientSeed:nonce)` |
| `server/catalog.js` | Предметы и кейсы, шансы и цены кейсов |
| `server/payments.js` | Заглушка платёжки. Сюда подключается провайдер |
| `data/items.json` | Каталог: `[оружие, скин, тип, редкость, цена в монетах, картинка]` |
| `data/grumgrade.db` | База, создаётся сама |
| `public/` | Фронтенд |

## Как устроена честность

- Результат каждой игры считает сервер: `HMAC-SHA256(серверный сид, "клиентский сид:nonce")`, первые 52 бита делятся на 2^52.
- Хэш серверного сида игрок видит до игры. Клиентский сид он может поменять сам.
- После смены серверного сида старый раскрывается, и любую прошлую игру можно пересчитать. Проверка встроена в окно «Честная игра» (значок щита).
- Апгрейд выигран, если ролл < шанс. Шанс = `ставка / цена цели × (1 − UPGRADE_HOUSE_EDGE)`, максимум `UPGRADE_MAX_CHANCE`.
- Кейс: шанс предмета пропорционален 1/цена. Цена кейса = матожидание × (1 + `CASE_MARGIN`). Шансы показаны на странице кейса.

## Цены

- Источник — публичный API Skinport: один запрос на все предметы, фазы допплеров (Ruby, Sapphire, Phase 1–4) учитываются. Если предмета нет на Skinport, цена берётся с market.csgo.com.
- 1 монета = 1 ₽ × `PRICE_MULTIPLIER`. Валюта задаётся в `PRICE_CURRENCY`.
- Сервер сам обновляет цены каждые `PRICE_UPDATE_HOURS` часов (по умолчанию 6) и сразу пересчитывает цены кейсов. Открытые вкладки подхватывают новые цены автоматически.
- Обновить вручную: `npm run prices`.
- Износ (FT/MW/FN…) выбирается один раз при первом обновлении и дальше не меняется.
- Если цена изменилась больше чем в `PRICE_MAX_JUMP` раз, она не применяется и попадает в лог. Это защита от кривых данных.
- Ручные цены задаются в `data/price-overrides.json` и важнее рынка: `{ "AK-47 | Redline": 2500 }`.
- Предметы в инвентаре оцениваются по текущей цене: и при продаже, и как ставка в апгрейде.

## API

- `GET /api/config`, `/api/catalog`, `/api/me`, `/api/stream` (SSE: дропы, онлайн, счётчики)
- `GET /auth/steam` → Steam → `/auth/steam/return`; `POST /auth/logout`; `POST /auth/demo` (только DEMO_MODE)
- `POST /api/upgrade {uids, amount, target}`, `POST /api/cases/:id/open`, `POST /api/sell {uids}`
- `POST /api/fair/client-seed {seed}`, `POST /api/fair/rotate`, `GET /api/fair/history`
- `POST /api/topup {amount}`, `POST /api/payments/webhook`
- `POST /api/trade-url {url}`, `POST /api/withdraw {uid}`
- Админка (SteamID64 в `ADMIN_STEAM_IDS`): `GET /api/admin/stats`, `GET /api/admin/withdrawals?status=pending`, `POST /api/admin/withdrawals/:id {status: sent|rejected}`

Все POST-запросы требуют `Content-Type: application/json` и заголовок `x-grum: 1`. Это защита от CSRF.

## Что осталось до боевого запуска

1. **Лицензия.** Приём денег на апгрейды и кейсы — это азартные игры. Без лицензии в своей юрисдикции подключать оплату нельзя. Valve запрещает скин-гемблинг и банит аккаунты ботов таких сайтов.
2. **Оплата.** `server/payments.js`: создание платежа и вебхук с проверкой подписи. Зачисление идёт через `creditDeposit()`, повторно оно не начислит.
3. **Вывод скинов.** Сейчас заявки ставятся в очередь (`withdrawals`), и админ закрывает их вручную. Для автовывода нужен Steam-бот (steam-user + steam-tradeoffer-manager) с инвентарём скинов.
4. **Хостинг.** HTTPS (nginx/Caddy перед Node), `BASE_URL=https://домен`, `DEMO_MODE=0`, бэкап `data/grumgrade.db`.
